# Product Summary

FIND is a web application for searching and reviewing case documents for the Criminal Injuries Compensation Authority (CICA). It is operated by the UK Ministry of Justice.

Users access the application via Tempus, select a case by its Case Reference Number (CRN), then search and view scanned document pages (images and OCR text) associated with that case.

Key capabilities:
- Full-text search across document pages using OpenSearch
- Image viewing of scanned document pages stored in S3
- OCR text view of document pages
- Pagination of search results
- Microsoft Entra ID (Azure AD) authentication
- Search context preservation across page navigation
